    What is ImageMaster?

    ImageMaster is a powerful, lightweight browser extension fully optimized for Microsoft Edge. It scans active tabs for all embedded, lazy-loaded, and background CSS image files, presenting them in a beautiful visual grid for easy collection.

    Why use the Extension?

    Unlike web-based tools, browser extensions run locally inside your page tab. This means it can bypass login gates, scrape images inside private forums, bypass CAPTCHAs, and download protected assets without being blocked by origin server firewalls.

    Microsoft Edge Extension FAQ

    Answers to common compatibility and privacy questions.

    Does ImageDownloader work on Microsoft Edge?

    Yes. ImageDownloader has a dedicated Edge extension available on the Microsoft Edge Add-ons store, free to install. It works on all Chromium-based Edge versions.

    Can I use the Chrome extension on Edge?

    Yes, since Microsoft Edge is Chromium-based, it supports Chrome extensions. You can install ImageDownloader from the Chrome Web Store and it will work on Edge just as well.

    Is ImageDownloader approved for the Edge Add-ons store?

    Yes, ImageDownloader is listed and approved on the official Microsoft Edge Add-ons store. It has passed Microsoft's security and privacy review.

    Does it work on Edge for Mac and Linux?

    Yes. Microsoft Edge is available on Windows, macOS, and Linux, and ImageDownloader works on all platforms where Edge is installed.
