What is ImageMaster?

ImageMaster is a powerful, lightweight browser extension designed specifically for the Google Chrome web browser. It scans active tabs for all embedded, lazy-loaded, and background CSS image files, presenting them in a beautiful visual grid for easy collection.

Why use the Extension?

Unlike web scraping tools, a browser extension runs locally inside your page tab. This means it can bypass login gates, scrape images inside private forums, bypass CAPTCHAs, and download protected assets without being blocked by origin server firewalls.

Chrome Extension FAQ

Answers to common technical and privacy questions.

Why does the extension require permission to read page data?

To detect and extract images embedded on a webpage, Chrome requires the extension to read the HTML source of the active tab. This process is done locally on your computer; no browsing history or private data is ever collected or sent to our servers.

Does it work with Brave, Edge, and Opera?

Yes. Brave, Microsoft Edge, and Opera are built on the Chromium engine. You can install ImageMaster from the Chrome Web Store directly into these browsers, and all features will function exactly the same.

How does the HD Image Resolver work?

Social media and e-commerce websites like Instagram, Pinterest, and Amazon load small cropped thumbnails to speed up page loads. When you run ImageMaster on these sites, our resolver automatically rewrites those URL paths to pull the original high-resolution, uncropped master file directly from their content delivery networks (CDNs).

Are updates automatic?

Yes. Chrome automatically checks for updates in the background and will update ImageMaster to the latest release version without interrupting your workflow.
