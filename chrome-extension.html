What is ImageMaster?

ImageMaster is a powerful, lightweight browser extension designed specifically for the Google Chrome web browser. It scans active tabs for all embedded, lazy-loaded, and background CSS image files, presenting them in a beautiful visual grid for easy collection.

Why use the Extension?

Unlike web scraping tools, a browser extension runs locally inside your page tab. This means it can bypass login gates, scrape images inside private forums, bypass CAPTCHAs, and download protected assets without being blocked by origin server firewalls.

Chrome Extension FAQ

Answers to common technical and privacy questions.

Is ImageDownloader free for Chrome?

Yes, ImageDownloader is completely free to install and use on Google Chrome. There is no premium tier, no subscription, and no account required. Simply install it from the Chrome Web Store and start downloading images immediately.

How do I install ImageDownloader on Chrome?

Go to the Chrome Web Store and search for "ImageDownloader," or click the Install button on this page. Click "Add to Chrome" and confirm the permissions. The extension installs in under 60 seconds and appears in your browser toolbar immediately.

Can I download images in bulk with the Chrome extension?

Yes. Click the ImageDownloader icon on any webpage to see a grid of all images on that page. You can select individual images or click "Select All," then download them all at once. The images are saved to your device as a ZIP file.

What image formats does ImageDownloader support?

ImageDownloader supports all major image formats including JPG/JPEG, PNG, WebP, GIF, SVG, and BMP. It detects and downloads all images on the page regardless of format.

Is the Chrome extension safe? Does it collect my data?

ImageDownloader is safe to use. It only activates when you click the icon — it does not run in the background or track your browsing. It does not collect, store, or share any personal data. The extension has been reviewed and approved by the Chrome Web Store.

Why can't I download images from some websites?

Some websites block access to their images using security policies (CSP headers) or serve images from protected CDNs. In these cases, ImageDownloader may not be able to access the image files directly. We recommend only downloading images you have permission to use.

Does ImageDownloader download images in full resolution?

Yes. ImageDownloader downloads the original image file served by the website, which is typically full resolution. It does not compress or resize images during download.

Can I filter images by size before downloading?

Yes. ImageDownloader lets you filter images by minimum width and height, so you can skip small icons and buttons and only download the large, high-quality images you need.
