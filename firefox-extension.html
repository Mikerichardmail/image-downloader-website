Firefox Addon FAQ

Commonly asked questions regarding browser compatibility and features.

Does the Firefox Addon support Private Browsing?

Yes. By default, Firefox disables extensions in Private Windows. To enable ImageMaster in Private mode, go to `about:addons`, select ImageMaster, and under 'Run in Private Windows', check 'Allow'.

If I buy the Pro license, does it work on Chrome too?

Yes! Your Gumroad license key is universal. It works to unlock Pro features on both our Google Chrome Extension and Firefox Addon.

Why can't the extension fetch images on local file:// links?

Browser security guidelines prevent extensions from accessing local file paths by default. You can enable local file access in the extension's settings panel under `about:addons` if you need to scrape local HTML files.
