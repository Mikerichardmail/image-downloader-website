Firefox Addon FAQ

Commonly asked questions regarding browser compatibility and features.

Is ImageDownloader available for Firefox?

Yes! ImageDownloader is available as a free addon on the official Mozilla Firefox Add-ons store (addons.mozilla.org). It works on all versions of Firefox including Firefox ESR.

Does the Firefox addon have the same features as Chrome?

Yes, the Firefox addon is feature-identical to the Chrome extension. You get the same image grid view, bulk download, size filtering, ZIP export, and format support on Firefox.

Is the Firefox addon safe and approved by Mozilla?

Yes. ImageDownloader has been reviewed and approved by Mozilla's addon review team. It collects no personal data and only activates when you click the icon. Your browsing history is never accessed or stored.

How do I install ImageDownloader on Firefox?

Click the "Add to Firefox" button on this page or visit the Firefox Add-ons store. Click "Add to Firefox," approve the permissions, and the extension will appear in your toolbar within seconds.

Does it work on Firefox for Android?

Firefox for Android supports a limited set of extensions. Check the Firefox Add-ons store page for ImageDownloader to see the latest Android compatibility status.
