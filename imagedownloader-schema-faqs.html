Chrome Extension — FAQ Content
Paste these Q&As into your /chrome-extension page
Is ImageDownloader free for Chrome? ▼
Yes, ImageDownloader is completely free to install and use on Google Chrome. There is no premium tier, no subscription, and no account required. Simply install it from the Chrome Web Store and start downloading images immediately.
How do I install ImageDownloader on Chrome? ▼
Go to the Chrome Web Store and search for "ImageDownloader," or click the Install button on this page. Click "Add to Chrome" and confirm the permissions. The extension installs in under 60 seconds and appears in your browser toolbar immediately.
Can I download images in bulk with the Chrome extension? ▼
Yes. Click the ImageDownloader icon on any webpage to see a grid of all images on that page. You can select individual images or click "Select All," then download them all at once. The images are saved to your device as a ZIP file.
What image formats does ImageDownloader support? ▼
ImageDownloader supports all major image formats including JPG/JPEG, PNG, WebP, GIF, SVG, and BMP. It detects and downloads all images on the page regardless of format.
Is the Chrome extension safe? Does it collect my data? ▼
ImageDownloader is safe to use. It only activates when you click the icon — it does not run in the background or track your browsing. It does not collect, store, or share any personal data. The extension has been reviewed and approved by the Chrome Web Store.
Why can't I download images from some websites? ▼
Some websites block access to their images using security policies (CSP headers) or serve images from protected CDNs. In these cases, ImageDownloader may not be able to access the image files directly. We recommend only downloading images you have permission to use.
Does ImageDownloader download images in full resolution? ▼
Yes. ImageDownloader downloads the original image file served by the website, which is typically full resolution. It does not compress or resize images during download.
Can I filter images by size before downloading? ▼
Yes. ImageDownloader lets you filter images by minimum width and height, so you can skip small icons and buttons and only download the large, high-quality images you need.

Firefox Addon — FAQ Content
Paste these Q&As into your /firefox-addon page
Is ImageDownloader available for Firefox? ▼
Yes! ImageDownloader is available as a free addon on the official Mozilla Firefox Add-ons store (addons.mozilla.org). It works on all versions of Firefox including Firefox ESR.
Does the Firefox addon have the same features as Chrome? ▼
Yes, the Firefox addon is feature-identical to the Chrome extension. You get the same image grid view, bulk download, size filtering, ZIP export, and format support on Firefox.
Is the Firefox addon safe and approved by Mozilla? ▼
Yes. ImageDownloader has been reviewed and approved by Mozilla's addon review team. It collects no personal data and only activates when you click the icon. Your browsing history is never accessed or stored.
How do I install ImageDownloader on Firefox? ▼
Click the "Add to Firefox" button on this page or visit the Firefox Add-ons store. Click "Add to Firefox," approve the permissions, and the extension will appear in your toolbar within seconds.
Does it work on Firefox for Android? ▼
Firefox for Android supports a limited set of extensions. Check the Firefox Add-ons store page for ImageDownloader to see the latest Android compatibility status.

Edge Extension — FAQ Content

Does ImageDownloader work on Microsoft Edge? ▼
Yes. ImageDownloader has a dedicated extension for Microsoft Edge available on the Microsoft Edge Add-ons store. It is free to install and works on all versions of Edge (Chromium-based).
Can I install the Chrome version on Edge instead? ▼
Yes. Since Microsoft Edge is Chromium-based, it supports Chrome extensions. You can install ImageDownloader directly from the Chrome Web Store and it will work on Edge just as well.
Is ImageDownloader approved for the Edge Add-ons store? ▼
Yes, ImageDownloader is listed and approved on the official Microsoft Edge Add-ons store. It has passed Microsoft's security and privacy review.
Does ImageDownloader work on Edge for Mac and Linux? ▼
Yes. Microsoft Edge is available on Windows, macOS, and Linux, and ImageDownloader works on all platforms where Edge is installed.

Bulk Image Downloader — FAQ Content
Paste these Q&As into your /bulk-image-downloader page
How do I download all images from a website at once? ▼
Install ImageDownloader, navigate to the webpage containing the images, and click the extension icon. A panel will show every image on the page. Click "Select All" then "Download" — all images will be saved to your device as a ZIP file in seconds.
Is there a limit to how many images I can download at once? ▼
There is no hard limit set by ImageDownloader. You can download hundreds of images at once. Very large batches may take a moment to package into a ZIP file depending on your connection speed.
Can I filter images by size when bulk downloading? ▼
Yes. ImageDownloader includes a size filter so you can set a minimum image width and height. This lets you skip small icons and ads, and only bulk download the large, meaningful images on the page.
Are bulk downloaded images saved as a ZIP file? ▼
Yes. When you download multiple images, ImageDownloader packages them into a ZIP file that downloads to your default downloads folder. You can then extract the ZIP to access all the images.
Does bulk download work on image-heavy sites like Pinterest or Instagram? ▼
Yes. ImageDownloader works on social media platforms and image-heavy sites. Scroll down the page to load more images before opening the extension for the most complete results.
What browsers support the bulk image downloader? ▼
ImageDownloader's bulk download feature is available on Google Chrome, Mozilla Firefox, and Microsoft Edge. It works the same way on all three browsers.
